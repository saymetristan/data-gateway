# Guía de Mapeo Semántico

Una vez que tu fuente de datos está conectada y perfilada, tienes que decirle al Data Gateway qué columnas exponer y bajo qué reglas.

## 1. Estructura del Documento

Prepara un archivo `mapping.json`. [Revisa los Conceptos de Mapeo](/concepts/semantic-mapping) si necesitas entender la teoría.

```json
{
  "document": {
    "entities": [
      {
        "entity": "product",
        "displayName": "Producto",
        "pluralLabel": "Productos",
        "sourceTable": "products",
        "embeddingTextTemplate": "{{title}} - {{description}}. Color: {{color}}",
        "fields": [
          {
            "name": "id",
            "sourceColumn": "sku",
            "type": "string",
            "identifier": true
          },
          {
            "name": "category",
            "sourceColumn": "category",
            "type": "string",
            "searchable": true,
            "filterable": true,
            "aliases": ["categoría", "coleccion"],
            "retrieval": {
              "inferredBehavior": "prefer",
              "boost": 0.3,
              "searchWeight": "B"
            }
          },
          {
            "name": "title",
            "sourceColumn": "name",
            "type": "string",
            "searchable": true,
            "retrieval": { "searchWeight": "A" }
          },
          {
            "name": "price",
            "sourceColumn": "cost",
            "type": "number",
            "filterable": true
          },
          {
            "name": "stock",
            "sourceColumn": "qty",
            "type": "number",
            "visible": true
          }
        ],
        "defaultFilters": [
          { "field": "stock", "op": "gt", "value": 0 }
        ]
      }
    ]
  }
}
```

En este ejemplo:
- Creamos la entidad `product`. En el MCP se creará la herramienta `search_product`.
- `title` es `searchable` con peso `A`: domina el ranking léxico.
- `category` es `filterable` + `inferredBehavior: "prefer"`: en NL prioriza sin excluir; el agente también puede usar `prefer_category` o el arg duro `category`.
- `price` es `filterable`: parámetro explícito para rangos.
- `defaultFilters`: el agente nunca verá stock ≤ 0.

Guía completa de filter vs prefer vs search: [Ranking y Preferencias](/concepts/ranking-and-preferences).

## 2. Aplicar el Mapping

Con tu archivo listo, envíalo al endpoint de la fuente:

```bash
curl -X POST "https://data.whaapy.com/sources/{source_id}/mapping" \
  -H "Authorization: Bearer $WORKSPACE_KEY" \
  -H "Content-Type: application/json" \
  -d @mapping.json
```

La fuente pasará al estado `mapped` (nueva versión activa).

## 3. Indexar los datos

Para que el mapeo tome efecto —incluidos `searchWeight`, `cardinality: many` y el texto searchable— regenera el índice:

```bash
curl -X POST "https://data.whaapy.com/sources/{source_id}/index" \
  -H "Authorization: Bearer $WORKSPACE_KEY"
```

Dependiendo del volumen, tarda segundos o minutos. Al terminar, el estado será `indexed`.

<Warning>
  Cambiar `searchWeight`, reglas o qué campos son `searchable` exige reindex.
  Para sinónimos usa [políticas de retrieval](/onboarding/synonym-updates): se evalúan
  y activan sin reindex. Solo regenera embeddings si cambió
  `embeddingTextTemplate` o los datos del template.
</Warning>
